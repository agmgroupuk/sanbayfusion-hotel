# Social icons

Monochrome SVG silhouettes sourced from Simple Icons (CC0), 2 October 2026:
https://github.com/simple-icons/simple-icons/tree/develop/icons
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Facebook, Instagram, TikTok, LINE and WhatsApp assets are rendered in Sanbay gold.
The matching 48px PNGs are generated from these SVGs for email-client compatibility.
Platform marks remain the property of their respective owners.

Link configuration and confirmation status live in lib/site.ts. Having an icon
does not enable a link: LINE and WhatsApp remain disabled until direct URLs are supplied.
